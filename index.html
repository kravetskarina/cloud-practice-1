Про застосунок

Сторінку створено в GitHub Codespaces, збережено в репозиторії GitHub і опубліковано через GitHub Pages.

Хмарні технології

  • GitHub — зберігання програмного коду
  • GitHub Codespaces — хмарне середовище розробки
  • GitHub Pages — розгортання вебзастосунку

Хмарний сервіс: Supabase

Supabase — хмарна платформа з відкритим кодом, яка дає вебзастосунку готовий бекенд: базу даних PostgreSQL, вхід користувачів і файлове сховище без налаштування власного сервера.

Моделі хмарних послуг: PaaS і BaaS (бекенд як сервіс), частково DBaaS — керована хмарна база даних.

Приклади функцій: Database (PostgreSQL), Auth, Storage, Edge Functions, Realtime.
